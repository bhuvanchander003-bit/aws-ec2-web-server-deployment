Project Overview

I designed and deployed a Linux-based web server on AWS. The infrastructure uses Amazon VPC, a public subnet, Internet Gateway, Route Table, Security Group, EC2, Elastic IP and CloudWatch.

☁️ Amazon EC2

Provides the Linux virtual server used to host this website.

🌐 VPC

Provides the isolated network environment for the AWS infrastructure.

🔒 Security Group

Controls inbound traffic such as HTTP and SSH access to the server.

🖥️ Apache

Apache HTTP Server delivers this HTML and CSS website to users.

📊 CloudWatch

Monitors EC2 performance and server metrics.

📍 Elastic IP

Provides a persistent public IPv4 address for accessing the server.

Architecture Flow

Internet → Internet Gateway → Public Subnet → Security Group → EC2 → Apache → Website
